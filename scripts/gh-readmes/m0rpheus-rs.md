# m0rpheus-rs

TUI Postgres workbench with embedded MCP server — vim-mode, schema tools, Claude/Cursor integration.

**Intent**

m0rpheus-rs is a from-scratch Postgres workbench in Rust, designed as a single static binary that brings a vim-mode TUI, schema tools, and a built-in MCP server together into one workspace.

**Tech stack**

- Rust
- ratatui
- tokio
- sqlx
- MCP
- PostgreSQL

*Status: dev*
