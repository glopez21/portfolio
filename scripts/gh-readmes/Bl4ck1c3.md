# Bl4ck1c3

Rust smart firewall — libpcap capture, DPI, anomaly ML, nftables enforcement, live dashboard.

**Intent**

Bl4ck1c3 is a Rust-native smart firewall deployed across the homelab fleet — a controller on clu5t3r, edge gateways on multiple hosts, and agents reporting host telemetry over a self-signed mesh.

**Tech stack**

- Rust
- axum
- tokio
- sqlx
- libpcap
- nftables
- pnet
- Chart.js

*Status: live*
