# r4g

Agentic RAG + MCP from first principles — no LangChain, no LlamaIndex, pure Rust/Python engineering.

**Intent**

r4g is a from-scratch agentic RAG system built to demonstrate depth in retrieval, tool use, and agent design — without relying on LangChain, LlamaIndex, or any orchestration framework.

**Tech stack**

- Python
- Rust
- ollama
- BM25
- MCP
- Hybrid Retrieval
