# s3arc

From-scratch search engine — BM25 ranking, full-text indexing, and relevance scoring over a Markdown corpus.

**Intent**

s3arc is a from-scratch information retrieval engine — building the full indexing and ranking pipeline without relying on Elasticsearch, Meilisearch, or any external search infrastructure.

**Tech stack**

- Python
- BM25
- Inverted Index
- TF-IDF
- CLI
