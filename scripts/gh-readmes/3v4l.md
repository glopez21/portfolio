# 3v4l

LLM evaluation and observability harness — eval suites, hallucination scoring, and a Grafana dashboard.

**Intent**

3v4l (EvalKit) is an LLM evaluation and observability harness — a system for measuring how well your language models are actually performing on your data, with the metrics flowing into a live Grafana dashboard.

**Tech stack**

- Python
- ollama
- Prometheus
- Grafana
- Eval

*Status: dev*
