# n3xus-flow

Local-first CI/CD runner with TUI — DAG pipelines, cron triggers, and artifact collection.

**Intent**

n3xus-flow is a local-first CI/CD pipeline runner with a ratatui TUI — designed to replace manual deployment scripts with a structured, auditable pipeline that runs entirely on your local machine or homelab server.

**Tech stack**

- Rust
- ratatui
- tokio
- YAML
- TUI

*Status: dev*
