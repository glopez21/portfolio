# ShadowSim

SOC traffic simulator — 43 attack modules covering kernel, firmware, cloud, supply-chain, and LLM attacks.

**Intent**

ShadowSim is the SOC ecosystem's threat generator — a modular simulation engine that produces realistic security events for testing detection pipelines, training analysts, and validating response playbooks.

**Tech stack**

- Python
- Modular
- MITRE ATT&CK
- Docker

*Status: live*
