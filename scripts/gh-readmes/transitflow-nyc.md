# transitflow-nyc

Real-time NYC transit data pipeline — ETL, Postgres, ML, and live dashboards.

**Intent**

transitflow-nyc is a full-stack data engineering project: ingesting real-time MTA transit feeds, storing them in a time-series Postgres schema, running ML prediction and clustering models, and rendering the results in an interactive dashboard.

**Tech stack**

- Python
- FastAPI
- PostgreSQL
- ML
- Chart.js
- Docker

*Status: dev*
