# rust-infer

Production model inference server in Rust — model registry, /predict, and Prometheus metrics.

**Intent**

rust-infer is a production-grade model inference server in Rust, designed to serve ML models behind a well-instrumented REST API with full Prometheus metrics integration.

**Tech stack**

- Rust
- axum
- ONNX Runtime
- Prometheus
- REST

*Status: research*
