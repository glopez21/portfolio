# Analyst Agent

SOC analyst co-pilot — NL queries over security data, RAG over threat intel, and automated playbook triggering.

**Intent**

The Analyst Agent is the AI flagship of the SOC ecosystem — a natural language co-pilot that lets a security analyst query their infrastructure using plain English and trigger complex response workflows without writing detection queries manually.

**Tech stack**

- Python
- ollama
- MCP
- RAG
- Tool Calling
- Streamlit
