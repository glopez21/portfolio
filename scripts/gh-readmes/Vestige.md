# Vestige

DFIR memory forensics toolkit — memory diffing, YARA generation, and LLM-assisted forensic reports.

**Intent**

Vestige is a digital forensics and incident response toolkit focused on memory analysis — the practice of extracting forensic artifacts from running system memory dumps.

**Tech stack**

- Python
- YARA
- LLM
- Forensics
- CLI
